# FoldReader

Читалка для Samsung Galaxy Z Fold 7 (и любого Android 8+) с «живым»
перелистыванием: страницу можно тянуть пальцем, она загибается как бумажная.

## Возможности

- **Физическое перелистывание.** Лист изгибается по цилиндру вслед за пальцем
  (`Canvas.drawBitmapMesh`, освещение по вершинам, тень на нижней странице).
  Отпустили — страница долистывается или возвращается (учитывается скорость
  жеста). Тап по краю — анимированный перелист, клавиши громкости тоже листают.
- **Разворот на Fold.** На внутреннем экране (ширина ≥ 600dp) книга
  открывается разворотом: правая страница отрывается от корешка и ложится на
  левую, на обороте листа — следующая страница. На внешнем экране — одна
  страница. Складывание/раскладывание не теряет место чтения.
- **Форматы:** FB2, FB2.ZIP, EPUB, TXT (UTF-8 / windows-1251).
- **Типографика:** выключка по ширине, переносы (русские/английские),
  красная строка, заголовки, эпиграфы, стихи, сноски.
- Темы День / Сепия / Ночь, антиква / гротеск, размер шрифта, оглавление,
  ползунок по книге. Позиция сохраняется для каждой книги.

## Книги из ЛитРес

Приложение ЛитРес хранит книги зашифрованными внутри себя, другие приложения
до них добраться не могут, а рисовать «поверх» чужого приложения Android не
даёт. Поэтому FoldReader берёт файлы, которые ЛитРес разрешает скачать:

1. litres.ru → «Мои книги» → книга → «Скачать» → FB2 или EPUB.
2. В FoldReader: «Папка с книгами» → выбрать `Download`. При каждом запуске
   новые книги из папки подтягиваются автоматически. Либо просто открыть
   скачанный файл — Android предложит FoldReader.

## Сборка

`./gradlew :reader:assembleDebug` → `reader/build/outputs/apk/debug/`.
CI (`.github/workflows/build-reader-apk.yml`) собирает APK и выкладывает его
в релиз `foldreader-apk-latest`.

## Устройство кода

- `book/` — парсеры (`Fb2Parser`, `EpubParser`, `TxtParser`) в `Spanned`-текст.
- `reader/Paginator.kt` — разбивка глав на страницы (`StaticLayout`, лениво).
- `reader/PageRenderer.kt` — отрисовка страниц в битмапы, темы.
- `reader/CurlView.kt` — жесты и физика загиба страницы.
- `library/Library.kt` — библиотека, импорт, синхронизация папки.
