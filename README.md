# Змейка 8-бит (Snake 8-Bit)

Классическая "Змейка" для Android на Kotlin + Jetpack Compose, поле 20×30
клеток, оформление в стиле ретро 8-бит игр.

## Как играть

- Змейка постоянно движется, съедает яблоки (красные клетки) и растёт.
- После каждого съеденного яблока на поле появляется новое постоянное
  препятствие (серый блок).
- Два варианта управления, переключаются кнопкой (↺/✛) в правом верхнем
  углу HUD, выбор запоминается:
  - **Руль** (↺) — тап по левой половине экрана поворачивает налево, по
    правой — направо, относительно текущего движения змейки.
  - **4 зоны** (✛) — экран делится по диагоналям на 4 огромных сектора:
    верх/низ/лево/право — абсолютные направления, как D-pad, но без
    маленьких кнопок.
  В обоих случаях зоны — это весь игровой экран целиком, играть можно
  вслепую, не целясь в конкретную точку.
- Кнопка паузы (⏸/▶) в левом верхнем углу останавливает и возобновляет игру.
- Выход за край поля не убивает змейку — она появляется с противоположной
  стороны (wraparound).
- Каждые 10 съеденных яблок открывается бонусное окно на 10 секунд: все
  препятствия на это время можно есть как яблоки (они мигают серым/красным).
  Вне бонусного окна столкновение с препятствием, как и с собственным
  хвостом, — конец игры.
- Счёт показывается на экране game over, рестарт по тапу начинает игру
  заново (поле снова пустое от препятствий).
- Скорость игры немного растёт с каждым съеденным яблоком.
- Звук: короткие 8-бит "биты" (квадратная волна, без аудиофайлов) на
  поедание яблока, game over и переключение паузы.

## Структура проекта

- `app/src/main/java/.../game/SnakeGame.kt` — логика игры (без UI):
  сетка, повороты — и относительные (`turnLeft`/`turnRight`), и абсолютные
  (`queueDirection`), столкновения, спавн яблок и препятствий, пауза.
- `app/src/main/java/.../audio/SoundEngine.kt` — процедурная генерация
  чиптюн-звуков через `AudioTrack` (без внешних аудиофайлов).
- `app/src/main/java/.../ui/SnakeGameScreen.kt` — экран на Compose: рендер
  поля через `Canvas`, HUD с кнопкой паузы и переключателем схемы
  управления, оверлеи старта/паузы/game over, два варианта тап-зон
  (`SteeringControls` / `FourZoneControls`).
- `app/src/main/java/.../ui/theme` — ретро-палитра (4 оттенка зелёного в
  духе классических портативных консолей) + акцентный красный для яблока.

## Сборка

Открыть папку проекта в Android Studio (Koala/Ladybug и новее) — она сама
подтянет Gradle и SDK. Либо из терминала (нужен установленный Android
SDK):

```
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.

> В этой сессии сборка не проверялась через `gradlew`, т.к. окружение не
> имеет доступа к Android SDK и к репозиторию Google Maven (`dl.google.com`)
> — оттуда загружается Android Gradle Plugin и AndroidX. Код написан и
> вычитан вручную; при первом открытии в Android Studio возможны мелкие
> правки версий плагинов/зависимостей, если к моменту сборки выйдут более
> новые релизы AGP/Compose BOM.
